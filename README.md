# SecondShelf

Sell it before it expires.

Lagos food distributors scan cartons, list stock at a discount six weeks before expiry, and get paid through Access Bank. Each handover adds to a Business Passport a bank can lend against.

```bash
npm install
npm run dev        # http://localhost:3000
npm test
npm run build && npm start
```

- `CHANGES.md`: what changed, what's mocked, and the stage demo script
- `DEMO.md`: printable demo barcodes
- `AUDIT.md`: audit of the previous front end

Phone cameras need HTTPS. See "Running it" in `CHANGES.md`.
